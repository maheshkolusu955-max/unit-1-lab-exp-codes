# Web Design Mini Projects

This project contains three simple web page designs created with HTML
and CSS.

## 1. Personal Portfolio

A personal portfolio page introducing Azeez and presenting basic profile
information.

**Sections included:** - About Me - Education - Skills: HTML, CSS,
Python - Hobbies - Contact

## 2. Online Learning Platform

A sample online learning page that presents introductory courses.

**Courses included:** - HTML Course --- Learn the basics of HTML. - CSS
Course --- Learn how to design webpages. - Python Course --- Learn
Python programming.

Each course includes an **Enroll Now** button.

## 3. NRI University Website

A simple college information page for NRI University.

**Sections included:** - About Our College - Departments: Computer
Science, Cyber Security, Electrical and Electronics Engineering, and
Civil Engineering - Admissions - Contact Us

## Technologies Used

-   HTML
-   CSS

## How to View

1.  Keep the project HTML files together in a folder.
2.  Open the desired `.html` file in a web browser.
3.  If you edit the HTML or CSS, save the file and refresh the browser
    to see the changes.

## Purpose

These mini projects demonstrate basic webpage structure, headings,
paragraphs, lists, simple layouts, colors, and course or college
information sections.
